# 最后三页

一款完全发生在一本日记里的纯文字悬疑恐怖推理游戏。

玩家阅读顾澄在 2004 年留下的日记，点击句子制作页边摘录，再利用时间、称呼、门锁与前后矛盾完成四次阶段推理，最后判断日记末三页的真正作者。

## 在线游玩

## 体验原则

- 不跳转到其他网站或档案页面。
- 所有剧情与证据都来自日记原文。
- 普通句子和关键证据采用相同交互，不直接标示答案。
- 推理必须引用玩家亲手摘录的原句。
- 同样能够证明结论的语义等价摘录可以替代标准答案。
- 提示按“方向提示—日期定位—正确摘录”递进；第三层可一键装入正确证据，但不会自动提交。
- 每次阶段推理后都有读者写在页边的内心独白，让判断逐步从“找矛盾”转向“认识顾澄”。
- 六处可翻开的纸页折角形成第二层悬疑线索；它们不会增加答题条件，但会揭示日记曾被翻动、抽页与补写。
- 四角操作区采用高对比度按钮，阅读、摘录、前后翻页与合上书签都有明确反馈。
- 合上日记会保留书签、当前章节、摘录与纸页痕迹，并根据阅读进度显示不同的封面异动。
- 最终结论严格区分“日记能够证明的事实”和“无法证实的推测”。
- 终章通过划掉伪造文字、辨认封底压痕和留下一句没有对错的封底批注完成情绪收束。
- 阅读进度、摘录、标签和推理结果保存在当前设备。
